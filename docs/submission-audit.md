## 비밀정보와 사용자 원문 저장 점검

점검 결과:

- `.env`, `.streamlit/secrets.toml`, `*.log`는 Git 추적 대상이 아니다.
- `.gitignore`가 `.env`, `.streamlit/secrets.toml`, 피드백 `incoming` 원본을 제외한다.
- 현재 제출 배포는 `OPENAI_API_KEY`를 사용하지 않는다.
- 현재 파일과 Git 이력에서 OpenAI 비밀키 형태인 `sk-…` 값을 발견하지 못했다.
- Git 이력의 `OPENAI_API_KEY` 문자열은 환경 변수 조회 또는 값이 없는 문서 예시뿐이다.
- 앱은 사용자 입력을 파일·DB·표준 출력·애플리케이션 로그에 기록하지 않는다.
- 사용자 입력은 요청 처리 중 지역 변수로 사용되고, 세션에는 구조화 분석과 마스킹 타입만
  유지한다. 새 분석 시 추가 확인 세션 상태를 정리한다.
- 평가 스크립트의 파일 출력은 명시적으로 실행할 때만 생성되며 합성 평가 데이터와
  마스킹된 전송문을 대상으로 한다.

저장소 코드 감사로 확인할 수 없는 Streamlit 플랫폼 자체 운영 로그 정책은 별도 영역이다.
앱 코드에서는 사용자 원문을 로그로 보내지 않는다.
