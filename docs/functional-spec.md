# MVP 기능명세서

## 서비스 목적

금융사기 여부를 확정하지 않고 사용자가 설명한 상황에서 확인된 피해 노출과 즉시 대응 행동을 안내한다.

## 기능 목록

| ID | 기능 | 입력 | 처리 | 출력·예외 |
|---|---|---|---|---|
| F01 | 고정 긴급 안내 | 없음 | AI와 독립적으로 표시 | 송금·악성 앱 긴급 행동 |
| F02 | 상황 입력 | 최대 3,000자 | 빈 입력 검증 | 분석 요청 또는 안전 안내 |
| F03 | 민감정보 마스킹 | 사용자 원문 | 외부 전송 전 로컬 치환 | 마스킹된 텍스트만 전달 |
| F04 | 구조화 추출 | 마스킹된 텍스트 | Pydantic Structured Output | 검증된 행동 상태 |
| F05 | 추가 질문 | requested·unknown 상태 | 최대 3개 질문을 한 번만 확인 | 반영 완료 또는 미확인 상태 유지 |
| F06 | 다차원·복합 판단 | 확인된 done 상태 | 7개 노출 축 보존·합성 | 복합 노출 요약과 상태 집합 |
| F07 | 대표 단계 | 다차원 상태 | 규칙 기반 LEVEL 0~5 | 사용자용 요약 단계 |
| F08 | 행동 조합 | 모든 노출 상태 | 공식 지침 조회·정렬 | 즉시·다음·증거 보존 |
| F09 | 근거 표시 | 분석·지침 메타데이터 | 중복 출처 제거 | 위험 신호·공식 출처·확인일 |
| F10 | 샘플 시연 | 7개 사전 정의 사례 | 동일 규칙 파이프라인 실행 | 기대 단계·행동 |
| F11 | 장애 대응 | API·파싱·입력 오류 | 최대 2회 시도 후 fallback | 고정 안전 안내 유지 |

## 비기능 요구사항

- 로그인 없이 공개 URL에서 실행한다.
- 사용자 원문과 결과를 DB에 저장하지 않는다.
- 비밀키를 저장소에 커밋하지 않는다.
- 행동 지침은 LLM이 생성하지 않는다.
- 색상만으로 위험 수준을 표현하지 않는다.
- 공식 지침은 배포 전 URL과 최신성을 재확인한다.

## 환경 변수

| 이름 | 필수 여부 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | 자유 입력 분석에 필수 | 서버 환경에서만 설정 |

키가 없을 때도 앱과 샘플 시연, 고정 긴급 안내는 정상 작동한다.

## 현재 구현 상태 (2026-08-14)

- 추가 확인은 미응답 검증 후 한 번만 제출하며 완료 즉시 질문 영역을 닫는다.
- `잘 모르겠음`은 반복 질문하지 않고 미확인 상태로 안전하게 유지한다.
- 앱 설치·개인정보 제공·송금처럼 여러 행동이 함께 있으면 각 상태를 독립적으로 보존한다.
- 복합 피해는 실질 피해 영역을 카드로 표시하고 모든 영역의 공식 지침을 합쳐 정렬한다.
- 단순 상황 6개와 복합 피해 1개, 총 7개 샘플을 제공한다.
- 규칙·지침·UI 보조 로직 자동 테스트 36개가 통과한다.
